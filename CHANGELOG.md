# Changelog

## 0.1.0

First release.

- Polygon-driven download and caching of USGS 3DEP elevation (1 arc-second to
  1 m) and NLCD land cover.
- Point-to-point link analysis: path profile, Fresnel clearance, Longley-Rice
  (ITM), free space + delta-Bullington diffraction, gaseous absorption, two-way
  link budget, P.530 microwave availability.
- Area coverage with 3-D antenna patterns, clutter heights and P.2108 terminal
  clutter loss.
- 93 built-in antenna profiles and MSI / Planet pattern import.
- Linux installers: .deb, .rpm, AppImage, and an Arch PKGBUILD.
